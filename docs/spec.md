# 仕様

Chrome の縦タブモードで使う前提の、タブ数をスマートに管理する拡張機能。
縦タブの一覧 UI は Chrome 本体に任せ、拡張は「開きすぎたタブの自動整理」と設定ポップアップに徹する。

## 目的

縦タブの一覧でスクロールが必要になる = タブを開きすぎ、とみなし、使っていない間に自動でスイープする。

## 用語

- **容量**: 縦タブ一覧にスクロール無しで表示できる行数の推定値。
- **使用行数**: 縦タブ一覧で実際に使っている行数。
- **維持率 N%**: 容量に対して維持する割合。目標行数 = 容量 × N%。

## 行数の推定

- 容量 = `floor((ウィンドウ高 − 固定分) ÷ 行の高さ)`。固定分・行の高さは設定値(px)。
- Chrome 拡張から縦タブ一覧の実寸やスクロール状態は取得できないため推定値を使う。
- 使用行数:
  - グループ無しのタブは 1 タブ 1 行。
  - グループはヘッダー 1 行 + 展開中ならタブ数。折りたたみ中はヘッダー 1 行のみ。
  - タブが無いグループはヘッダーも数えない。
  - ピン留めタブも 1 行として数える(実機での表示は要確認)。

## スイープ

- 使用行数が目標行数を超えているとき、目標以下になるまで `lastAccessed` が古い順に閉じる(同値は id 昇順)。
- 閉じない: ピン留め、アクティブ、音声再生中、折りたたまれたグループ内のタブ。
- グループのタブを全て閉じるとヘッダー行も解放される。
- 閉じる候補が尽きたら、目標に届かなくてもそこで止める。
- ウィンドウごと(通常ウィンドウのみ)に独立して判定する。

## ドメイン順の並べ替え

スイープの後に、各ウィンドウのタブを hostname 昇順に並べ替える(`sortByDomain` が有効なとき)。

- hostname は URL から取り出し、先頭の `www.` は除く。URL が無い・不正な場合は空文字(先頭側)。
- 同一 hostname 内は元の並びを維持する。
- ピン留めタブは先頭のまま動かさない(ピン留め同士の順序も変えない)。
- グループ内のタブは動かさない(グループの位置も、グループ内の並びも変えない)。
- グループ外のタブは、グループで区切られた連続区間ごとに整列する。グループをまたいでタブを動かさない。
- スイープでタブを閉じた後の最新の index で計画する。スイープ後に Chrome へフォーカスが戻っていたら並べ替えない。

## 実行タイミング

Chrome を触っていないときだけ実行し、ブラウジング中は実行しない。

1. `windows.onFocusChanged` が `WINDOW_ID_NONE` を返したら(= 別アプリに切り替え)、`chrome.alarms` で待ち時間後のアラームを予約。
2. Chrome のウィンドウにフォーカスが戻ったらアラームを解除。
3. アラーム発火時、`windows.getLastFocused().focused` が true なら実行しない。
4. 全通常ウィンドウをスイープ。
5. 続けて、`sortByDomain` が有効なら全通常ウィンドウをドメイン順に並べ替える(直前にもう一度フォーカスを確認する)。

待ち時間は、ウィンドウ切替の一瞬の `WINDOW_ID_NONE` による誤爆を避けるためのもの。

## 設定

| 項目 | 初期値 | 範囲 | 説明 |
|---|---|---|---|
| `enabled` | `true` | - | 自動スイープの有効/無効 |
| `sortByDomain` | `true` | - | スイープ後のドメイン順の並べ替えの有効/無効 |
| `keepPercent` | 80 | 0〜100 | 維持率(%) |
| `rowHeight` | 32 | 1 以上 | 縦タブ 1 行の高さ(px)。暫定値 |
| `fixedHeight` | 120 | 0 以上 | 縦タブ一覧に使えない固定の高さ(px)。暫定値 |
| `delaySeconds` | 60 | 30 以上 | フォーカスが外れてから実行するまでの秒数(alarms の最短が 30 秒) |

`pnpm build:debug`(`--mode development`)でビルドすると、`delaySeconds` の初期値と下限が 10 秒になる(動作確認用。配布用ビルドは常に 60 秒・30 秒)。

保存先は `chrome.storage.local` の `settings` キー。不正値は `normalizeSettings` で補正する。

## ポップアップ(設定画面)

拡張アイコンのクリックで開く。変更は即座に `chrome.storage.local` へ保存する(保存ボタンなし)。

| 項目 | UI | 範囲 | 対応する設定 |
|---|---|---|---|
| 整理するまでの待ち時間 | スライダー(10 秒刻み) | 30〜600 秒(デバッグビルドは 10 秒から) | `delaySeconds` |
| 縦タブの使用率 | スライダー(5% 刻み) | 10〜100% | `keepPercent` |

### 閉じる予定のプレビュー

ポップアップを開いたウィンドウ(最後にフォーカスした通常ウィンドウ)について、**今の設定でスイープしたら閉じられるタブ**をタイトルで一覧表示する。

- 表示: `閉じる予定 (件数)` とタイトル(古い順、先頭 8 件。残りは `ほか N 件`)。対象が無ければ「閉じるタブはありません」。
- スライダーを動かすと即座に再計算する。実際のスイープと同じ `planSweep` を使うため、表示と実行は一致する。
- タイトルはポップアップの表示にのみ使い、保存も送信もしない。
- ウィンドウ情報を取得できない場合はプレビューを出さず、設定の操作だけ可能。
- 容量・使用行数・目標行数は UI に出さない(分かりにくいため)。値の確認は Service Worker のログ(`[tab-papa] sweep`)で行う。

他の設定(`enabled`、`sortByDomain`、`rowHeight`、`fixedHeight`)は現状 UI が無く、保存済みの値を保ったまま書き戻す。

## 権限

`tabs`, `tabGroups`, `storage`, `alarms`
