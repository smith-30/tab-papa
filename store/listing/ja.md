## 基本情報

- **名前**(75 文字以内): tab-papa
- **カテゴリ**: 仕事効率化(Productivity)
- **言語**: 日本語(デフォルト)

## 概要(Summary / 132 文字以内)

縦タブがあふれる前に整理。Chrome を離れている間に、開きすぎた古いタブを自動で閉じます。

## 詳細な説明(Description)

Chrome の縦タブモードで、タブ一覧がスクロールするほど開きすぎていませんか?
tab-papa は、使っていない間に古いタブを自動で片付けて、縦タブの一覧を「スクロール不要」に保つ拡張機能です。

■ こんなときに便利
・縦タブを使っていて、気づくと一覧が長くなっている
・タブを閉じるのが面倒で、つい溜めてしまう
・作業中に勝手にタブを閉じられるのは困る

■ 主な機能
・自動スイープ — ウィンドウの高さから縦タブ一覧に収まる行数を推定し、その一定割合(初期値 80%)を超えた分を、最後に開いた時刻が古いタブから閉じます。
・ブラウジング中は動きません — Chrome から別のアプリに切り替えて一定時間(初期値 60 秒)経ったときだけ実行します。Chrome に戻ると中断します。
・しっかり保護 — ピン留めしたタブ、いま開いているタブ、音声を再生中のタブ、折りたたまれたグループ内のタブは閉じません。
・グループにも対応 — タブグループのヘッダー行も含めて、一覧の行数を数えます。
・ドメイン順に整列 — 整理のあと、タブをドメイン順に並べ替えます(ピン留めタブとタブグループ内は動かしません)。設定でオフにできます。

■ 設定
・維持率(%)
・ドメイン順の並べ替えのオン/オフ
・縦タブ 1 行の高さ(px)など、ご利用の環境に合わせた調整

■ プライバシー
・外部サーバーとの通信は一切ありません。
・ドメイン順の並べ替えのためにタブの URL からホスト名を一時的に参照しますが、保存や送信はしません。タイトルは読み取りません。
・保存するのは設定値のみで、お使いの端末内(chrome.storage)に保存されます。

■ オープンソース
ソースコードは MIT ライセンスで GitHub に公開しています。

※ 縦タブの一覧の実寸は拡張機能から取得できないため、行数はウィンドウの高さからの推定値です。ずれる場合は設定で調整してください。

## 単一の目的(Single purpose)

Chrome の縦タブ一覧がスクロールするほど開きすぎたタブを、ブラウザを使っていない間に自動で閉じ、タブ数を適切に保つこと。

## 権限の理由(Permission justification)

| 権限 | 理由 |
|---|---|
| `tabs` | 各タブの最終アクセス時刻・ピン留め・アクティブ・音声再生の状態を参照し、閉じる対象を選んで閉じるため。また、ドメイン順に並べ替えるためタブを移動する。 |
| `tabGroups` | タブグループの折りたたみ状態を参照し、一覧で使っている行数(グループのヘッダー行を含む)を正しく数えるため。 |
| `storage` | 設定値(維持率・行の高さなど)を端末内に保存するため。 |
| `alarms` | Chrome から離れて一定時間後に整理を実行する待機のため(Service Worker は破棄されるためタイマーを使えない)。 |

- **リモートコード**: 使用しない
- **ホスト権限**: なし
