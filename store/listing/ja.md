## 概要(Summary / 132 文字以内)

縦タブがあふれる前に整理。Chrome を離れている間に、開きすぎた古いタブを自動で閉じます。

## 詳細な説明(Description)

tab-papa は、Chrome の縦タブがあふれる前に、使っていない間にそっと片付けてくれる拡張機能です。
インストールしたら、あとは放っておくだけ。

縦タブの一覧がスクロールするほど開きすぎていたら、Chrome から離れている間に、重複タブや古いタブを自動で閉じます。

■ 機能

・使用率スイープ
  ウィンドウの高さから縦タブ一覧に収まる行数を推定し、その一定割合(デフォルト 80%)を超えた分を、最後に見た時刻が古いタブから閉じます。

・重複クローズ
  同じウィンドウ内に同じ URL のタブが複数ある場合、使用率に関係なく、最後に見た 1 枚だけを残して閉じます。

・ドメイン整列
  整理のあと、タブをドメイン順に自動で並べ替えます。ピン留めタブとタブグループ内のタブは動かしません。

・閉じる前にプレビュー
  ポップアップで、今の設定で閉じられるタブをタイトルで確認できます。

■ ブラウジング中は動きません

別のアプリに切り替えて Chrome のフォーカスが外れ、設定した時間(デフォルト 60 秒)が経ったときだけ実行します。Chrome に戻ると中断します。

ピン留めタブ・いま開いているタブ・音声を再生中のタブ・折りたたまれたグループ内のタブは常に対象外なので、大事なタブが消えることはありません。

■ プライバシー — データは外部に一切送りません

外部サーバーへの通信はゼロ。重複の判定とドメイン整列のためにタブの URL を、プレビュー表示のためにタイトルを、その場で参照しますが、保存も送信もしません。
保存するのは設定値のみで、ブラウザ内(chrome.storage.local)にだけ置かれます。

■ 軽量

本体サイズは数十 KB。Chrome のフォーカスの切り替えを見ているだけで、整理するとき以外は何もしません。

■ オープンソース(MIT ライセンス)

ソースコードは GitHub で全公開しています。
https://github.com/smith-30/tab-papa

■ 設定

ポップアップから以下をカスタマイズできます。

・自動整理のオン/オフ
・整理するまでの待ち時間(デフォルト 60 秒、30〜600 秒)
・縦タブの使用率(デフォルト 80%、10〜100%)

※ 拡張機能からは縦タブ一覧の実際の大きさを取得できないため、収まる行数はウィンドウの高さからの推定値です。

## 単一の目的(Single purpose)

Chrome の縦タブ一覧がスクロールするほど開きすぎたタブを、ブラウザを使っていない間に自動で閉じ、タブ数を適切に保つこと。

## 権限の理由(Permission justification)

| 権限 | 理由 |
|---|---|
| `tabs` | 各タブの URL・最終アクセス時刻・ピン留め・アクティブ・音声再生の状態を参照し、重複や古いタブなど閉じる対象を選んで閉じるため。また、ドメイン順に並べ替えるためタブを移動し、閉じる予定のタブをポップアップに表示するためタイトルを参照する(保存・送信しない)。 |
| `tabGroups` | タブグループの折りたたみ状態を参照し、一覧で使っている行数(グループのヘッダー行を含む)を正しく数えるため。 |
| `storage` | 設定値(維持率・行の高さなど)を端末内に保存するため。 |
| `alarms` | Chrome から離れて一定時間後に整理を実行する待機のため(Service Worker は破棄されるためタイマーを使えない)。 |

- **リモートコード**: 使用しない
- **ホスト権限**: なし

- 収集するユーザーデータ: **なし**(個人を特定できる情報、健康、金融、認証、位置情報、ウェブ履歴、ユーザーの操作内容、ウェブサイトのコンテンツ、いずれも収集しない)
